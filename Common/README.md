# Common

특정 모듈에 속하지 않고 여러 모듈이 함께 쓰는 값만 둔다. 도메인 로직은 넣지 않는다 — 그건 각 모듈 소관이다.

- `KoreanTime.cs` — 한국 시간(KST) 오프셋 상수. 이 시스템의 "하루"는 전부 KST 기준이라(트렌드/이벤트 조회의 `date`, 운전일지 트리거 시각, 통신 단절 시 일자 경계 초기화) 서비스·컨트롤러 6곳이 각자 선언하던 값을 모았다(2026-09-18).

로그인 사용자 정보를 꺼내는 공용 헬퍼는 도메인(인증)에 속하므로 여기가 아니라 `Modules/Auth/CurrentUser.cs`에 있다.
