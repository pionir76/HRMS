# PC-LINK SUM 프로토콜

## 개요

- **통신 방식**: TCP/IP
- **프로토콜**: 삼원테크 PC-LINK SUM 프로토콜 (ASCII 기반)
- **통신 대상**: TLC(압축기 컨트롤러, TEMI2500)

## 공통 프레임 구조

모든 프레임은 `STX`로 시작하고 `SUM`(체크섬) + `CR` + `LF`로 끝난다.

```text
STX  국번(2)  커맨드(3)  , 필드1 , 필드2 , ...  SUM(2)  CR  LF
```

## 데이터 인코딩 규칙

- Data 값은 **소수점 없는 16진수**로 표현한다.
- 실수값은 소수점을 제거(소수점 1자리 기준 10배 스케일링)한 뒤 16진수로 변환한다.

| 실제 값 | 소수점 제거 | 16진수 변환 |
| ------- | ------------ | ----------- |
| 50.0 ℃  | 500          | `0x01F4`    |
| 30.0 ℃  | 300          | `0x012C`    |
| 0.5 ℃   | 5            | `0x0005`    |

---

## 1. RRD 커맨드 (랜덤 읽기)

D-Register 상의 임의 데이터를 읽을 때 사용하는 커맨드.

### 송신 포맷

| 필드    | STX | 국번 | RRD | , | 개수 | , | D-Reg-1 | , | … | , | D-Reg-n | SUM | CR  | LF  |
| ------- | --- | ---- | --- | - | ---- | - | ------- | - | - | - | ------- | --- | --- | --- |
| byte 수 | 1   | 2    | 3   | 1 | 2    | 1 | 4       | 1 | … | 1 | 4       | 2   | 1   | 1   |

### 수신 포맷

| 필드    | STX | 국번 | RRD | , | OK  | , | Data-1 | , | … | , | Data-n | SUM | CR  | LF  |
| ------- | --- | ---- | --- | - | --- | - | ------ | - | - | - | ------ | --- | --- | --- |
| byte 수 | 1   | 2    | 3   | 1 | 2   | 1 | 4      | 1 | … | 1 | 4      | 2   | 1   | 1   |

### 규칙

- 개수: 1 ~ 64 (한 번에 최대 64개 D-Register까지 조회 가능)
- Data: 16진수, 소수점 없는 정수

### 예제

온도 PV(D0001), 온도 SP(D0002)의 D-Register를 읽는 경우:

```text
송신                 : [STX]01RRD,02,0001,0002[CR][LF]
송신 (CheckSum 포함) : [STX]01RRD,02,0001,0002B2[CR][LF]
```

수신된 온도 PV(D0001) 값이 50.0, 온도 SP(D0002) 값이 30.0인 경우:

```text
수신                 : [STX]01RRD,OK,01F4,012C[CR][LF]
수신 (CheckSum 포함) : [STX]01RRD,OK,01F4,012C18[CR][LF]
```

## 2. WRD 커맨드 (랜덤 쓰기)

D-Register 상의 임의 데이터를 쓸 때 사용하는 커맨드.

### 송신 포맷

| 필드    | STX | 국번 | WRD | , | 개수 | , | D-Reg-1 | , | Data-1 | , | … | , | D-Reg-n | , | Data-n | SUM | CR  | LF  |
| ------- | --- | ---- | --- | - | ---- | - | ------- | - | ------ | - | - | - | ------- | - | ------ | --- | --- | --- |
| byte 수 | 1   | 2    | 3   | 1 | 2    | 1 | 4       | 1 | 4      | 1 | … | 1 | 4       | 1 | 4      | 2   | 1   | 1   |

### 수신 포맷

| 필드    | STX | 국번 | WRD | , | OK  | SUM | CR  | LF  |
| ------- | --- | ---- | --- | - | --- | --- | --- | --- |
| byte 수 | 1   | 2    | 3   | 1 | 2   | 2   | 1   | 1   |

### 규칙

- 개수: 1 ~ 64
- Data: 16진수, 소수점 없는 정수 (인코딩 규칙은 RRD와 동일)

### 예제

FIX운전 시 온도 SP(D0102)와 온도 SLOPE(D0106)에 값을 쓰는 경우:

```text
온도 SP 설정    : 50.0 ℃ → 소수점 제거(500) → 16진수화(0x01F4)
온도 SLOPE 설정 : 0.5 ℃  → 소수점 제거(5)   → 16진수화(0x0005)

송신                 : [STX]01WRD,02,0102,01F4,0106,0005[CR][LF]
송신 (CheckSum 포함) : [STX]01WRD,02,0102,01F4,0106,0005B6[CR][LF]
```

## 3. HRMS 실제 채널 조회 매핑

실제 사용하는 RRD 조회 명령:

```text
01RRD,009,0360,0361,0362,0364,0365,0366,0367,0099,1805
```

D-Register와 채널의 매핑은 다음과 같다.

| D-Register | 채널 / 용도       | 비고                              |
| ---------- | ----------------- | --------------------------------- |
| D0360      | CH01 저온          |                                    |
| D0361      | CH02 고온          |                                    |
| D0362      | CH03 오일(온도)    |                                    |
| D0364      | CH04 저압          | D0363은 조회 대상에서 제외(건너뜀) |
| D0365      | CH05 고압          |                                    |
| D0366      | CH06 오일압력      |                                    |
| D0367      | CH07 C/T(운전전류) |                                    |
| D0099      | UNUSED             | 조회하지만 값은 사용하지 않음     |
| D1805      | DOSTS              | Digital Output 상태 비트마스크, 비상정지 판정/제어에 사용 |

한 번의 RRD 요청으로 7개 센서 채널 + UNUSED + DOSTS, 총 **9개** 레지스터를 함께 조회한다.

---

## 4. 비상정지 구동 방안

DOSTS(D1805)는 Digital Output 상태를 담은 비트마스크이며, 그중 한 비트(`EmgStopBit`)가 비상정지 상태를 나타낸다.

### 비상정지 상태 확인

```csharp
if ((DOSTS & (0x0001 << EmgStopBit)) > 0)
{
    비상정지상태 = true;
}
```

### 비상정지 실행 / 해제

현재 DO 상태(`_nowDOSts`)를 읽고 `EmgStopBit`만 변경한 값을 WRD로 다시 써서, 다른 DO 비트에 영향을 주지 않는 read-modify-write 방식이다.

```csharp
public void EmgStop()
{
    if (_emgStopSts == true)
    {
        // 이미 비상정지 상태 -> 해당 비트를 0으로 클리어 (해제)
        Int16 val = Convert.ToInt16(_nowDOSts & ~(0x0001 << EmgStopBit));
        string cmd = string.Format("01WRD,001,1805,{0:X4}", val);
        Com.WriteCmd.Add(cmd);
    }
    else
    {
        // 정상 상태 -> 해당 비트를 1로 설정 (비상정지 실행)
        Int16 val = Convert.ToInt16(_nowDOSts | (0x0001 << EmgStopBit));
        string cmd = string.Format("01WRD,001,1805,{0:X4}", val);
        Com.WriteCmd.Add(cmd);
    }
}
```

이 구현은 현재 상태를 기준으로 실행/해제를 토글하는 방식이므로, 비상정지 해제(재운전) 명령도 동일한 메커니즘(D1805에 대한 WRD)으로 처리될 수 있다.

### 미확정 사항

- **`EmgStopBit`(비상정지에 해당하는 DOSTS 비트 위치)는 아직 결정되지 않았다.**
- 위 내용은 [overview.md 12장 추후 결정 필요사항](overview.md#12-추후-결정-필요사항)의 "비상정지 쓰기 패킷 상세", "비상정지 해제 및 재운전 기능 제공 여부"와 연결된다.
