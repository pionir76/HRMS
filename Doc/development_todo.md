  - [ ] 1분 단위 이력 데이터 (날짜+압축기 인덱스 설계)
  - [ ] 경보 설정 / 경보 발생·해제 이력
  - [ ] 운전 시작·정지 이력
  - [ ] 통신 장애·복구 이력
  - [ ] 비상정지 요청·결과 이력
  - [ ] 사용자 접속 로그 / 사용자 동작 감사 로그
  - [ ] 교육훈련 레포트 / 점검일지 / 운영일지 / 게시판 / 첨부파일
  - [ ] 시스템 설정
- [ ] REST API 엔드포인트 목록 및 요청/응답 스펙 초안 작성
- [ ] 내부 모듈 경계 설계 (통신/프로토콜/수집/실시간/경보/운전판정/비상정지/이력저장/API/인증/보고서·게시판/로그감사)
