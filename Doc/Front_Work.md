# HRMS

현대 남양 연구소 냉동기 모니터링 시스템 (Hyundai Namyang Refrigerator Monitoring System)

## 개요

현대 남양 연구소 내 냉동 관련 장비와 압축기의 운전 상태 및 센서 정보를 중앙 서버에서 통합 수집하고, 웹 기반 모니터링 시스템을 통해 확인할 수 있도록 하는 시스템입니다.

### 현재 목적

지금 진행하는 프론트엔드 개발은 **최종 개발이 아니라, 최종 개발에 앞서 백엔드 API 기능을 테스트하기 위한 목적**입니다. 최종 웹 UI는 추후 별도 디자인 작업을 거쳐 구현할 예정이므로, 지금 단계에서는 **최대한 간단하고 읽기 편하게** 작성합니다.

### 참고 사항

- 백엔드 기능 명세 및 업데이트 사항은 항상 [`reference/`](reference/) 폴더를 확인합니다 ([overview.md](reference/overview.md), [api-manual.md](reference/api-manual.md)).
- 이 문서와 `reference/` 문서의 내용이 서로 어긋나는 부분이 있으면, 화면 구현 전에 먼저 맞춰봐야 합니다 (하단 [11. 확인이 필요한 부분](#11-확인이-필요한-부분) 참고).

## 3. 실시간 현황

- 전체 장비의 리스트를 보여주며, 리스트 컬럼은 장비의 현재 상태와 관련된 항목(통신 상태, 알람, 운전 상태 등)으로 구성한다.
- 각 행 앞의 **펼침 아이콘**을 클릭하면 그 아래에 해당 장비에 속한 압축기들을 서브 리스트로 펼쳐서, 각 압축기의 현재 채널값과 통신/경보 상태를 보여준다. 다시 클릭하면 원래대로 접힌다. (아이콘이 아닌 행 자체를 클릭했을 때의 동작은 아래 참고)
- **행을 클릭**하면(펼침 아이콘 제외) 해당 장비의 [3.1 장비 실시간 화면](#31-장비-실시간-화면)으로 전환된다.
- 전체 시스템에서 발생하는 이벤트 리스트를 실시간으로 보여준다. (전체 시스템 부하를 고려한 설계가 필요하다. 어떤 이벤트를 남길지는 백엔드가 결정하며, 프론트는 내려오는 이벤트를 그대로 표시만 한다.)
- 다음 항목을 실시간 카운트로 보여준다.
    - 전체 냉동장비 / 압축기 수량
    - 현재 운전 중인 냉동장비 / 압축기 수량
    - 통신불량 압축기 수량

### 3.1 장비 실시간 화면

실시간 현황의 장비 리스트에서 행을 클릭하면 전환되는 장비 단위 상세 화면. 다음 항목으로 구성한다.

- **가동율** — 해당 장비의 운전 비율 (`GET /api/equipments/{id}/utilization`)
- **운전상태** — 해당 장비의 운전 상태
- **비상정지 버튼** — 해당 장비(및 소속 압축기)에 대한 비상정지 실행. (테스트 목적의 임시 배치이며, 최종 UI에서는 위치가 다시 정해질 수 있다. [4.8 비상정지 기능](reference/overview.md#48-비상정지-기능) 참고)
- **압축기 리스트** — 해당 장비에 속한 압축기 목록과 각각의 통신/경보 상태
- **압축기 클릭 시 트렌드** — 압축기 리스트에서 압축기를 클릭하면 해당 압축기의 현재(당일) 트렌드 기록 상황을 보여준다
- **이벤트 리스트** — 해당 장비에 대해서만 필터링된 이벤트 리스트

## 7. 장비 관리

- **장비**: 조회, 등록, 편집 (장비 사진, 설치 사진 2장 등록 가능)
- **검사 이력**: 등록, 조회, 편집 — 실시 일자, 제목, 점검내용, 첨부파일
- **수리보수일지**: 등록, 조회, 편집 — 제목, 일시, 장소, 철거 실행자, 대상, 이전 상태, 이후 상태, 결과, 고장 원인, 방지 대책, 의견
    - 결재 시스템 적용 (안전관리원은 결재란에 "해당없음" 의미로 `/` 표시)
- **압축기**: 장비에 대한 압축기 조회, 등록, 편집 (압축기별 설정, 압축기 채널 설정)

## 8. 교육훈련

- 교육훈련 조회, 등록, 편집
- 항목: 일시, 장소, 강사, 교육내용, 참석자 명단(단순 문자열로 저장 — 시스템 등록 인원과 무관), 첨부파일
- 결재 시스템: 안전관리원(해당 없음, `/` 표시 — 결재 불가) → 안전관리책임자 결재 → 안전관리총괄자 결재

## 9. 점검일지

장비별로 점검일지를 작성한다. **점검일지 1건 = 1주일(일요일~토요일)** 동안의 항목별 점검 데이터를 의미한다. (추후 최종 UI는 캘린더 형태로 작성 예정)

**좌측 — 작성 장비 선택창**

- 지역 선택: A지구 / B지구 / C지구
- 시설동 선택
- 설비(장비명) 선택
- 날짜 선택 (주 단위 — 예: "8월 첫째 주", "9월 마지막 주"처럼 주 단위 데이터 관리가 필요함)

**우측 — 콘텐츠 표시부**

- 선택된 장비에 대한 점검일지 조회 / 작성

## 10. 운전일지

장비별로 운전일지를 조회 / 작성한다.

**좌측 — 작성 장비 선택창**

- 지역 선택: A지구 / B지구 / C지구
- 시설동 선택
- 설비(장비명) 선택
- 날짜 선택 (일 단위)

**우측 — 콘텐츠 표시부**

- 선택된 장비에 대한 운전일지 조회 / 작성
- 결재 시스템: 안전관리원, 안전관리책임자, 안전관리총괄자

### 자동화 동작

운전일지는 다음과 같은 자동화 규칙을 따른다.

1. 각 항목별 **실측 기준**은 사용자가 편집할 수 있으며, 한 번 수정 저장하면 그 값이 이후 날짜의 운전일지에 기본값으로 자동 설정된다.
2. 매일 정해진 검사 시간이 되면 해당 시간대의 실측값이 압축기 채널값으로부터 자동 기입된다.
3. 해당 압축기가 통신 오류 상태이거나 실측 데이터를 읽어올 수 없으면, 실측값은 통신오류를 뜻하는 `/`로 표시한다.
4. 사용자가 체크 항목(`O`/`/`/`X`)을 수정하면, 그 값이 이후의 기본값이 되어 다음 검사 시간이 도래할 때 자동으로 같은 값이 체크된다 — **직전 체크 상태를 그대로 이어받는 방식**이다. (예: 9:00 값을 수정했고 다음 검사 시간이 21:00이라면, 그 사이에 있는 16:00 값을 따른다.)
5. 운전일지 작성은 **절대 누락되어서는 안 된다.** 백엔드가 정상 동작 중이라면 위 자동화 규칙에 따라 무조건 기록이 생성되어야 한다.

## 11. 확인이 필요했던 부분 (결정 사항)

원문을 정리하면서 발견했던 의문점과 그에 대한 답변을 정리한다. 실제 내용 반영 위치는 각 항목에 링크로 표시했다.

- ✅ **운전일지 표의 중복 행** → 냉각수온도/브라인온도는 (입구)/(출구) 두 지점을 각각 나타내는 것으로 확인. [10장 운전일지](#10-운전일지) 표에 반영함.
- ✅ **"기계 전류 ±10%"** → 오기 아니고 원문 그대로 사용. 다만 실측 기준값 자체가 사용자가 자유롭게 편집하는 항목이라 문구 정확성은 중요하지 않음.
- ✅ **비상정지 메뉴의 위치** → 별도 메뉴 없이, 실시간 현황에서 장비 행을 클릭해 들어가는 [장비 실시간 화면](#31-장비-실시간-화면)에 비상정지 버튼을 배치하기로 함 (테스트 목적의 임시 배치, 최종 UI에서는 위치 재검토).
- ✅ **경보 이력 조회 메뉴의 위치** → 별도 메뉴 불필요. 실시간 현황/자료 조회의 이벤트 리스트로 충분하며, 어떤 이벤트를 남길지는 백엔드가 결정하고 프론트는 내려오는 이벤트를 그대로 표시만 한다. [3장 실시간 현황](#3-실시간-현황)에 반영.
- ✅ **첨부파일 형식/용량** → 파일당 최대 10MB, 모든 첨부파일은 필수가 아닌 선택 사항, 다중 파일 첨부 가능. [13장 첨부파일 공통 규칙](#13-첨부파일-공통-규칙) 참고.
- ⏳ **`/` 기호의 중의성** (점검·운전일지의 "통신오류" vs 결재란의 "해당없음") → **추후 결정 (보류)**. 현재는 원문 표기를 그대로 유지한다.

## 12. 결재 시스템 공통 규칙

- 결재는 **정해진 순서**를 지켜야 한다 — 안전관리총괄자는 안전관리책임자보다 먼저 결재할 수 없다 (책임자 → 총괄자 순).
- 결재 대상에 해당하지 않는 역할은 결재란에 `/`로 표시한다. (예: 교육훈련에서 안전관리원은 결재란은 있지만 해당 사항이 없으므로 `/`로 표시하고 결재는 하지 않는다.)

## 13. 첨부파일 공통 규칙

공지사항, 검사 이력, 수리보수일지, 교육훈련 등 첨부파일을 다루는 모든 화면에 공통으로 적용된다.

- 파일당 최대 용량: **10MB 이하**
- 첨부파일은 **선택 사항**이며 필수 입력이 아니다.
- **다중 파일** 첨부가 가능하다.
