# Communication 모듈

TCP 통신 모듈 + 프로토콜 모듈.

- 압축기별 TCP 연결 관리 (연결/해제/재사용)
- 전용 프로토콜 파서 (요청 패킷 생성, 응답 패킷 파싱, 비정상 패킷 검출)
- 응답 타임아웃 처리 및 자동 재접속
- 압축기별 통신 상태 관리 (연결됨/끊김/재접속중)
- 압축기 통신 장애가 다른 압축기 수집에 영향을 주지 않도록 격리

## 내부 구성 (예정)

- `Protocol/` — 패킷 정의 및 파서
- `Client/` — 압축기별 TCP 클라이언트/세션 관리
- `Services/` — 연결 상태 관리
